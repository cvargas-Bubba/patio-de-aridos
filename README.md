# Patio de Áridos

Prototipo de una app para vender áridos (arena, gravilla, maicillo, base estabilizada, etc.).

- **Vista cliente:** catálogo, calculadora de m³, pedido con flete por zona e IVA, y coordinación de la entrega.
- **Vista vendedor:** pedidos, agenda de despachos, camiones, precios, stock y clientes.

Todos los precios, clientes y pedidos son de ejemplo. Los datos viven solo en la página y se borran al recargar.

Ver en línea: https://cvargas-bubba.github.io/patio-de-aridos/
